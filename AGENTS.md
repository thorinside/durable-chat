# Repository instructions

## Agent commits

- Agents making repository changes must run appropriate checks and commit their completed changes before reporting completion. Commit by default without asking for separate permission, unless the user explicitly requests no commit.
- Scope commits to your own work. Never include or revert unrelated changes.
- Do not push unless requested.
- Read-only and scouting jobs need no commit.
- If checks fail or a safe commit is blocked, report the blocker instead of making an unsafe commit.
