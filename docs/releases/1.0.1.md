# durable-chat 1.0.1

Patch release containing the independently approved TUI changes from
[PR #2](https://github.com/thorinside/durable-chat/pull/2) and
[PR #3](https://github.com/thorinside/durable-chat/pull/3).

## Multiline composer and paste preservation

- Shift-Enter inserts a newline; Ctrl-J and Alt-Enter are fallbacks for terminals
  that cannot distinguish Shift-Enter. Plain Enter still sends.
- The composer grows and scrolls with the draft. Arrow keys navigate text, and
  Backspace/Delete can join lines.
- Bracketed paste preserves line breaks, normalizes CRLF/CR to LF, and does not
  submit. Folded large pastes send their complete text; visual wrapping does not
  insert newline characters.

## Job transcript previews

- Browse jobs with j/k, Up/Down, or g/G to preview the highlighted job's transcript
  and live updates without changing the pinned composer or action target.
- Enter pins the selected job; Ctrl-T explicitly toggles the target. Tab into the
  transcript keeps the preview available for scrolling; returning to the composer
  restores the pinned target's transcript and preserves the draft.
- Automatic highlighting of arriving jobs no longer interrupts preview browsing.
  Confirmations continue to name the pinned target.

## Compatibility

Node.js 22.19.0 or newer is required. Both `dchat` and `durable-chat` aliases remain
available. Dependencies and MCP authentication behavior are unchanged: the closed,
unmerged bearer-shorthand PR #1 is not part of this release.

After publication, install from npm with lifecycle scripts disabled:

```sh
npm install -g durable-chat@1.0.1 --ignore-scripts --registry=https://registry.npmjs.org
```
